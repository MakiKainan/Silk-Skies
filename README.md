# SILK SKIES

A top-down spaceship duel roguelite made in Godot 4.7.

## Game flow

1. **Start screen:** pick a difficulty (Easy / Normal / Hard), then **Original** to start a run.
2. **Duel:** a 1v1 fight against one enemy ship. The current act, The Slice Gauntlet, is three duels: Raider, Longshot, then the boss, The Warden.
3. **Salvage:** after each win, take one of three items (or skip). Open **Refit** to make room or swap gear.
4. **Refit:** drag items onto your frigate's slots: weapons, fighter bays, techmods and crew.
5. Beat The Warden to clear the act. Lose a duel and the run is over.

**Debug** on the start screen opens a sandbox for testing ships and gear.

## Controls

| Key | Action |
| --- | --- |
| W / S | Thrust forward / reverse |
| A / D | Steer |
| Mouse | Aim |
| Left mouse | Fire left-mouse weapons |
| Right mouse | Fire right-mouse weapons (missile pod: hold on an enemy to lock, release to fire) |
| Shift | Hard Burn dash: W toward the mouse, S away, A / D to the sides |
| Tab / middle mouse | Lock on: aim leads the target and the ship turns its guns onto it |
| Q / E / R | Item abilities: launch fighters, EMP, repair, overcharge |
| I | Refit (inventory) |
| Esc | Close the refit screen |

In the refit screen, right-click a weapon to switch it between the left and right mouse buttons.
